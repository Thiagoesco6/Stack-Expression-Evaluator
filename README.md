# Stack-Based Mathematical Expression Evaluator

## Overview
This Python program reads mathematical expressions from input.txt,
evaluates them using a custom Stack class, and writes the results
to output.txt.

## Requirements
- Python 3
- No external packages are required.

## Project Files
- main.py: Stack class, expression evaluator, and file processing.
- input.txt: Expressions used for testing.
- output.txt: Results generated by the program.
- README.md: Instructions and limitations.

## How to Run
1. Place main.py and input.txt in the same folder.
2. Open a terminal in that folder.
3. Run:

```bash
python main.py
```

4. Open output.txt to see the results.

Each run replaces the previous contents of output.txt.

## Input Format
Write one expression per line. Separate expressions using lines
containing two or more hyphens, such as -----.
Blank lines and separator lines are preserved.

Example:

```text
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## Output Format
Expressions are replaced by their results:

```text
13
-----
16
-----
-10
```

Whole-number results are displayed without a decimal suffix.

## How the Program Works
The Stack class provides push, pop, peek, and is_empty operations.
It follows Last In, First Out (LIFO).

The evaluator uses two stacks:
- A number stack stores operands and intermediate results.
- An operator stack stores operators and opening parentheses.

Multiplication and division have higher precedence than addition
and subtraction. Operators of equal precedence are evaluated
from left to right. Parentheses control the evaluation order.

The program does not use eval().

## Error Handling
Invalid expressions produce an error message in output.txt.
Processing continues with the remaining expressions.

Errors include:
- Division by zero.
- Unmatched parentheses.
- Missing numbers or operators.
- Invalid numbers or characters.

File access errors are displayed in the terminal.

## Assumptions and Limitations
- Supports +, -, *, /, and parentheses.
- Supports whole numbers and decimal numbers.
- Does not support powers, variables, or mathematical functions.
- Unary signs are not supported: write (0 - 5) instead of -5.
- Multiplication must be explicit: use 2 * (3 + 4).
- Uses floating-point arithmetic, which may introduce rounding errors.
- Separator lines must contain only two or more hyphens,
  apart from surrounding whitespace.
